# API schemas

Generated by `cargo xtask schemas` from the code (sub-phase 0.9); don't edit.
`cargo xtask schemas --check` in CI fails when these files don't match the code
([09-testing §6](../architecture/09-testing.md)).

## Public API v1

Methods (params and result under `$defs`) and notifications.

| Name | What |
|---|---|
| [`Errors`](public/v1/errors.json) | The `data` of every error reply: clients branch on `kind`, never on the message. `x-codes` gives the JSON-RPC code of each kind. |
| [`v1.audit.verify`](public/v1/v1.audit.verify.json) | Checks that no event in the log was changed, removed or reordered. Read-only. |
| [`v1.events.ended`](public/v1/v1.events.ended.json) | A notification the daemon sends. |
| [`v1.events.event`](public/v1/v1.events.event.json) | A notification the daemon sends. |
| [`v1.events.subscribe`](public/v1/v1.events.subscribe.json) | Sends events as they happen, from a point in the log on. Read-only. Sends `v1.events.event`. |
| [`v1.events.unsubscribe`](public/v1/v1.events.unsubscribe.json) | Stops a subscription. Read-only. |
| [`v1.module.call`](public/v1/v1.module.call.json) | Calls one of a module's methods and returns its answer. |
| [`v1.module.disable`](public/v1/v1.module.disable.json) | Turns a module off; it stops now and stays off. |
| [`v1.module.enable`](public/v1/v1.module.enable.json) | Turns a module on; it starts now and with PriyaOS from then on. |
| [`v1.module.list`](public/v1/v1.module.list.json) | Lists the modules PriyaOS found and what each is doing. Read-only. |
| [`v1.settings.get`](public/v1/v1.settings.get.json) | Shows settings, and where each one came from. Read-only. |
| [`v1.settings.schema`](public/v1/v1.settings.schema.json) | Gives the JSON Schema of every setting. Read-only. |
| [`v1.settings.set`](public/v1/v1.settings.set.json) | Changes one setting in your settings file. |
| [`v1.settings.unset`](public/v1/v1.settings.unset.json) | Removes one setting from your settings file, so its default applies. |
| [`v1.system.doctor`](public/v1/v1.system.doctor.json) | Checks that PriyaOS is healthy, and can fix what it finds. |
| [`v1.system.methods`](public/v1/v1.system.methods.json) | Lists every request the API accepts. Read-only. |
| [`v1.system.status`](public/v1/v1.system.status.json) | Shows whether PriyaOS is running and what it is using. Read-only. |

## Modules

The manifest, and the protocol between priyad and a module (`x-direction` says who calls).

| Name | What |
|---|---|
| [`module.toml`](module/manifest.v1.json) | A module's manifest, API v1. |
| [`event`](module/host-v1/event.json) | Hands the module an event it subscribes to (host to module). |
| [`host.call`](module/host-v1/host.call.json) | Calls a read-only public API method (module to host). |
| [`host.emit_event`](module/host-v1/host.emit_event.json) | Records one of the module's own events (module to host). |
| [`host.settings.get`](module/host-v1/host.settings.get.json) | Reads a setting the module may see (module to host). |
| [`initialize`](module/host-v1/initialize.json) | Starts the session and asks the module who it is (host to module). |
| [`ping`](module/host-v1/ping.json) | Checks that the module still answers (host to module). |
| [`shutdown`](module/host-v1/shutdown.json) | Asks the module to finish up and exit (host to module). |
