# Words explained

| Word | Simple meaning | Example |
|---|---|---|
| **Operating system (OS)** | The main program that runs your computer | Windows, macOS, Arch Linux, PriyaOS |
| **Arch Linux** | The Linux PriyaOS is built on | The house we're furnishing |
| **Kernel** | The deepest part of the OS that talks to the hardware. We don't change it. | The engine of a car |
| **Package** | An app ready to install | An item in an app store |
| **pacman** | Arch's app installer | The checkout counter |
| **Package repo** | A server full of packages. PriyaOS has its own for Priya's parts. | Our own small app store |
| **ISO** | One file holding the whole installer; you put it on a USB | A flat-pack house in a box |
| **Model** | One AI "brain", like Claude Sonnet or GPT | One doctor |
| **Model family** | All the models from one company | All the doctors from one hospital |
| **Provider** | The company or program that runs a model (Anthropic, OpenAI, Google, xAI, Ollama…) | The hospital |
| **Local model** | An AI running on your own laptop, works offline | A family doctor who lives next door |
| **Token** | A small piece of text; AI companies charge per token | Paying per word |
| **Priya AI** | PriyaOS's own AI that picks the best model for each job | The hospital front desk |
| **Routing** | Choosing which model gets a job | Sending a patient to the right doctor |
| **Role** | The *kind* of model a job needs (fast, smart, coding, vision, private) | "Needs a specialist" vs "needs a nurse" |
| **Strategy** | Your choice of best / balanced / cheapest / local only | Your budget rules |
| **Cache** | Remembering earlier answers or message beginnings to save cost | Keeping a copy of the receipt |
| **Agent / AI worker** | An AI that can *do* things, not just chat | Claude Code, Codex, Gemini CLI |
| **Priya Orchestration** | Priya planning a big job and managing many AI workers | A project leader |
| **Plan** | A big job split into steps | A recipe |
| **Verifier** | A check that the work is right (tests, a second AI) | A second teacher grading |
| **Task / job** | One thing you asked for | "Set up Docker" |
| **Priya Sandbox** | An instant photocopy of the computer for the AI to work on | Practising on a photocopy |
| **btrfs** | The way PriyaOS stores files; it can take instant snapshots | A notebook that photocopies itself in a second |
| **Snapshot** | An instant, space-saving photo of files | A photo of your room |
| **Fork** | A writable copy of the whole computer | A photocopy you can draw on |
| **Diff / ChangeSet** | The list of what changed | "Added 2 apps, changed 5 files" |
| **Merge / keep** | Keeping the changes | Gluing the good parts back in |
| **Discard / throw away** | Not keeping the changes | Binning the photocopy |
| **Conflict** | You and the AI changed the same thing | Two people edited the same page |
| **Execution mode** | How careful a job is: just look / sandbox / directly with snapshot / directly | How careful the mechanic is |
| **Rollback** | Going back to the previous system | Undo for the whole computer |
| **Priya Rewind** | The timeline of every change, with undo of any one | A video recording you can rewind |
| **Timeline snapshot** | Automatic hourly photo of the system | A CCTV snapshot |
| **Memory** | What Priya remembers about you and your projects | A notebook about you |
| **Index** | A searchable list of your files' contents | A library catalogue |
| **MCP** | A standard plug that lets AI workers use tools | A universal tool plug |
| **Tool index** | The phone book of apps AI workers can use | The phone book |
| **Module / block** | One feature plugged into Priya's core | A LEGO piece |
| **priyad** | Priya's background manager program | The office manager |
| **Helper** | The tiny program with full control, no internet, no AI | The vault guard |
| **Policy / permission rule** | What each AI worker may and may not do | House rules |
| **Approval** | Priya asking you before doing something | "May I?" |
| **Taint / Untrusted** | The job read something from the internet; check more carefully | A note from a stranger |
| **Secrets** | Passwords, keys, logins hidden from AI workers | A locked diary |
| **Audit log** | The diary of everything that happened, sealed page by page | A logbook with numbered, stamped pages |
| **Kill switch** | Stops all AI workers instantly (Super + Shift + Escape) | The big red button |
| **Priya Vision** | Priya understanding your screen and pictures | Priya's eyes |
| **Speech-to-text / text-to-speech** | Turning voice into words and words into voice | Priya's ears and mouth |
| **Wake word** | "Hey Priya" | Calling someone's name |
| **Hyprland** | The program that draws windows on your screen | The walls and windows |
| **Quickshell** | What we use to build Priya's bar, panels and notifications | The furniture maker |
| **GRUB** | The start menu where you pick PriyaOS or Windows | The front door with two bells |
| **EFI partition** | A small shared start-up area for Windows and PriyaOS | The building's shared lobby |
| **BIOS / UEFI setup** | The laptop's settings screen before any OS starts (F2 on ASUS) | The fuse box |
| **Secure Boot** | Only lets signed start-up programs run | A guard at the door |
| **BitLocker** | Windows' disk lock; needs a recovery key if start-up settings change | A safe's backup code |
| **Encryption (LUKS)** | Locks your PriyaOS disk with a password | A safe for your files |
| **Virtual machine (VM)** | A whole pretend computer inside a window | A flight simulator |
| **Rust** | The programming language Priya's core is written in | The language of the instructions |
| **Phase** | One stage of building PriyaOS | One floor of a building |
