# Data

Files PriyaOS ships as-is, such as the model catalog (Phase 1) and default settings.

- `defaults/`: the default settings, installed to `/usr/share/priya/defaults/`.
- `prompts/`: Priya AI's prompts, installed to `/usr/share/priya/prompts/`.
- `desktop/`: the lines a desktop adds for the Priya bar, installed to `/usr/share/priya/desktop/`: `hyprland.lua` for Hyprland 0.55 and later, `hyprland.conf` for older configs.
